# Junior Developer Opportunities India

A community-maintained directory of junior developer opportunities in India, with official application links and last-checked dates.

## Why this project exists

Finding suitable entry-level developer roles takes time. This project brings clearly sourced opportunities into one place so applicants can check requirements and visit the official application page.

## What we include

- Internships and junior developer roles relevant to applicants in India.
- Roles requiring 0–2 years of professional experience.
- Opportunities with a publicly accessible official job listing.
- Remote roles whose official listing explicitly allows applicants in India.

## How we check entries

- Read the official job listing before adding an opportunity.
- Record requirements as stated; do not guess missing details.
- Write "Not specified" when a requirement is not provided.
- Record the date checked using YYYY-MM-DD.
- Remove closed listings when their status is confirmed.

A last-checked date records when a contributor reviewed the listing. It does not guarantee that the role remains open or that an applicant is eligible.
